Number Guessing Game: A joyful activity for family and friends!
The name is self-explainable: you just have to guess a number that was made up by a computer.

The rules are pretty simple:
1) The number is in a range from 1 to 100 (entering the number out of the range WILL lead to unexpected consequences).
2) Do not mess with the code.
3) Have fun!
